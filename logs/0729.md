# version 1
由於 CortexDC 匯出的 InfluxDB 資料為 long format，每筆資料僅代表單一時間、單一 measurement 與 field 的數值，因此模型訓練前需先進行資料轉換。第一版 以時間與 server_name 作為索引，將 server_temperature、server_power、server_fan 與 server_cpu 等資料整合為 wide format。CPU temperature 由 sensor_name 中包含 CPU Temp、CPU1 Temp、CPU2 Temp 或 CPU package temperature 的感測器取得，並排除 VRM、DIMM、PCH、Peripheral 與 System 類型感測器；inlet temperature 則由 Inlet Temp、Inlet Ambient 或 System Board Inlet Temp 取得。若同一時間點存在多個 CPU 或風扇感測器，則取平均值作為該時間點的代表值。
- 輸入：目前與過去的 CPU 溫度、進氣溫度、server power、fan rpm
- 輸出：未來第 10 筆有效觀測點的 CPU 溫度
- 資料：8 台 server 的 CortexDC 資料
- 處理：多 sensor 合併成代表值，非 CPU 溫度排除
- 切分：70% train、15% validation、15% test
