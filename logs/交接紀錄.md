## XGBoost 資料格式摘要

- 原始檔可為 CSV 或 JSON。
- 每列一筆樣本，每欄一個 scalar feature 或 target。
- InfluxDB fields 支援 float、integer、string、boolean。
- 不可直接寫 nested arrays；需展開為 feature_0、feature_1 等。
- Feature Group 的 feature_list 包含所有 inputs 與 target。
- 分類使用 XGBClassifier；迴歸使用 XGBRegressor。
- XGBoost 通常不需要 StandardScaler。
- 記錄 dataset version、feature order、target、split、套件版本、參數與 metrics。
