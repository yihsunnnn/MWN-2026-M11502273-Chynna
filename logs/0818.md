# CortexDC / SMO 常用操作指令整理

## 1. SSH 登入

### 登入 srsric VM

```bash
ssh srsric@192.168.8.48
```

用途：

* 操作 CortexDC Collector
* 執行 `query_smo.py`
* 查看 CSV
* 查看 CortexDC → SMO Bridge

### 登入 SMO

```bash
ssh ubuntu@192.168.8.69
```

用途：

* 操作 Kubernetes
* 查看 SMO InfluxDB
* 查看 Pod / Service

---

## 2. 查看目前所在位置

```bash
pwd
```

例如：

```text
/home/srsric
```

---

## 3. 查看資料夾內容

```bash
ls
```

看詳細資訊：

```bash
ls -lh
```

看隱藏檔案：

```bash
ls -la
```

例如查看 CortexDC Collector：

```bash
ls -lh ~/cortexdc_collector/
```

---

## 4. 查看 CSV 檔案

CSV 存放位置：

```text
/home/srsric/cortexdc_collector/smo_exports/
```

查看有哪些 CSV：

```bash
ls -lh ~/cortexdc_collector/smo_exports/
```

依最新時間排序：

```bash
ls -lt ~/cortexdc_collector/smo_exports/
```

只看最新幾個：

```bash
ls -lt ~/cortexdc_collector/smo_exports/ | head
```

---

## 5. 查看 CSV 內容

看前 20 行：

```bash
head -20 ~/cortexdc_collector/smo_exports/檔名.csv
```

看最後 20 行：

```bash
tail -20 ~/cortexdc_collector/smo_exports/檔名.csv
```

看完整檔案：

```bash
cat ~/cortexdc_collector/smo_exports/檔名.csv
```

資料很多時：

```bash
less ~/cortexdc_collector/smo_exports/檔名.csv
```

離開：

```text
q
```

---

## 6. 執行 SMO 資料查詢工具

```bash
~/cortexdc_collector/venv/bin/python3 \
~/cortexdc_collector/query_smo.py
```

功能：

```text
SMO InfluxDB
    ↓
選 Measurement
    ↓
選 Server
    ↓
選 Sensor
    ↓
選 Field
    ↓
選時間範圍
    ↓
輸出 CSV
```

目前支援：

```text
單選：1

複選：
1,3,5

全選：
all
```

---

## 7. 檢查 Python 程式語法

修改完 `query_smo.py` 後：

```bash
~/cortexdc_collector/venv/bin/python3 \
-m py_compile \
~/cortexdc_collector/query_smo.py
```

如果：

```text
沒有任何輸出
```

表示 Python 語法正常。

## 8. 編輯 Python 程式

```bash

```

Nano 常用操作：

```text

→ 儲存

Enter
→ 確認檔名

Ctrl + X
→ 離開

Ctrl + K
```

清空整份檔案：

```bash

```

## 10. 查看 CortexDC → SMO 自動同步狀態

```bash
sudo systemctl status cortexdc-smo-bridge --no-pager
```

正常：

```text
Active: active (running)
```

表示：

```text
CortexDC Local InfluxDB
        ↓
每 60 秒
        ↓
SMO InfluxDB
```

正在自動同步。

---

## 11. 查看即時同步 Log

```bash
sudo journalctl -u cortexdc-smo-bridge -f
```

例如：

```text
Read 812 records from CortexDC.
Wrote 812 records to SMO successfully.
Checkpoint updated.
Sync completed successfully.
```

離開：

```text
Ctrl + C
```

只會離開 Log，不會停止 Bridge。

---

## 12. 重新啟動 Bridge

```bash
sudo systemctl restart cortexdc-smo-bridge
```

停止：

```bash
sudo systemctl stop cortexdc-smo-bridge
```

啟動：

```bash
sudo systemctl start cortexdc-smo-bridge
```

## 19. 查看 SMO 中有哪些 Measurement

在 srsric VM：

```bash
SMO_TOKEN=$(cat ~/cortexdc_collector/smo_token)
```

再查：

```bash
curl -s \
-H "Authorization: Token $SMO_TOKEN" \
-H "Content-Type: application/vnd.flux" \
-H "Accept: application/csv" \
-X POST \
"http://192.168.8.69:30138/api/v2/query?org=ravi-ric" \
--data 'import "influxdata/influxdb/schema"

schema.measurements(
    bucket: "cortexdc-server",
    start: -24h
)'
```

目前確認：

```text
server_cpu
server_fan
server_power
server_temperature
```

## 20. 把 CSV 從 VM 下載到 Windows

先離開 VM：

```bash
exit
```

回到：

```text
C:\Users\User>
```

輸入：

```cmd
scp srsric@192.168.8.48:/home/srsric/cortexdc_collector/smo_exports/檔名.csv C:\Users\User\Downloads\
```

例如：

```cmd
scp srsric@192.168.8.48:/home/srsric/cortexdc_collector/smo_exports/SMO_query_20260818_151944.csv C:\Users\User\Downloads\
```

即可使用 Excel 開啟。
